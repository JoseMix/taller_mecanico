Modelo de Datos — v2

Con tabla de Clientes independiente

Cliente
🔑 id INTEGER PK
nombre TEXT
apellido TEXT
telefono TEXT
direccion TEXT
localidad TEXT
provincia TEXT
1 ——< N
Vehicle
🔑 id INTEGER PK
🔗 cliente_id FK → Cliente
matricula TEXT UNIQUE
marca TEXT
modelo TEXT
año INTEGER
1 ——< N
Order (central)
🔑 id INTEGER PK
numero_orden TEXT UNIQUE
🔗 vehicle_id FK → Vehicle
estado TEXT ENUM
descripcion TEXT
fecha_entrada DATETIME
fecha_actualizacion DATETIME
fecha_entrega DATETIME NULL
1 ——< N
BudgetItem
🔑 id INTEGER PK
🔗 order_id FK → Order
concepto TEXT
tipo ENUM (mano_obra | pieza)
cantidad NUMERIC
precio_unitario NUMERIC
Cadena de relaciones
Cliente (1) ──→ (N) Vehicle (1) ──→ (N) Order (1) ──→ (N) BudgetItem
  • Un cliente puede tener muchos vehículos; un vehículo pertenece a un único cliente
  • Un vehículo puede tener muchas órdenes históricas; solo 1 activa simultáneamente
  • Al buscar por matrícula, se recupera el vehículo → cliente → historial de órdenes
  • La factura PDF incluye datos del cliente (nombre + apellido + dirección + localidad + provincia)
