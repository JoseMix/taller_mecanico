🔑 id INTEGER PK
numero_orden TEXT UNIQUE
🔗 vehicle_id FK → Vehicle
estado TEXT ENUM
descripcion TEXT
fecha_entrada DATETIME
fecha_actualizacion DATETIME
fecha_entrega DATETIME NULL
1 ——< N
BudgetItem
🔑 id INTEGER PK
🔗 order_id FK → Order
concepto TEXT
tipo ENUM (mano_obra | pieza)
cantidad NUMERIC
precio_unitario NUMERIC
Reglas de integridad
  • numero_orden se genera automáticamente al crear: formato YYYY-NNN (ej: 2024-001)
  • estado solo puede ser uno de: recibida | presupuestado | en_reparacion | finalizada | entregado | rechazado
  • Un vehículo solo puede tener una orden con estado activo (no entregado ni rechazado)
  • BudgetItems no se pueden añadir/editar/borrar si la orden está en en_reparacion, finalizada, entregado o rechazado
  • El total del presupuesto se calcula como suma de cantidad × precio_unitario de todos los items
